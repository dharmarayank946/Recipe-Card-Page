# VEDA Technology Web Development Internship Task 11 — Recipe Card Page

A clean, attractive, and fully responsive **Recipe Card Page** built strictly using **HTML5** and **CSS3**. This project presents a complete, authentic recipe for **Vegetable Fried Rice**, designed with a soothing light cream background, soft green accents, semantic markup, and mobile-friendly typography.

## 🎯 Objectives
1. Build an attractive, modern, and accessible recipe card for **Vegetable Fried Rice**.
2. Structure the content cleanly using semantic HTML5 elements (`<main>`, `<article>`, `<figure>`, `<figcaption>`, `<header>`, `<section>`, `<ul>`, `<ol>`, `<footer>`).
3. Display essential recipe metadata including **Preparation Time**, **Cooking Time**, and **Servings**.
4. Organize ingredients in a clean unordered list (`<ul>`) with at least 8 items (14 items provided).
5. Outline step-by-step preparation instructions using an ordered list (`<ol>`) with at least 5 numbered steps (6 steps provided).
6. Implement a calming, clean aesthetic utilizing a light cream background, rounded white card, and soft green accents.
7. Ensure 100% responsiveness across all mobile, tablet, and desktop screens without horizontal scroll.
8. Deliver a pure static web solution without JavaScript, build tools, external libraries, or complex terminal dependencies.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic elements (`<main>`, `<article>`, `<figure>`, `<figcaption>`, `<header>`, `<section>`, `<ul>`, `<ol>`, `<footer>`) for structure and accessibility.
- **CSS3:** Responsive layout using CSS Grid, Flexbox, custom properties (variables), clean box shadows, rounded borders, and custom list markers.
- **Google Fonts:** `Plus Jakarta Sans` for modern and legible typography.
- **Local Assets:** High-resolution optimized food photograph (`fried-rice.jpg`) stored locally to prevent broken external links.

## 🚀 How to Run the Project Locally
Since this project uses pure HTML5 and CSS3:

1. **Directly in Any Browser:**
   - Download or clone this repository.
   - Navigate to the `Task11-Recipe-Card-Page` folder.
   - Double-click `index.html` to open it in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.
   - No terminal, Node.js, npm, or build step is required!

2. **Using a Local Server (Optional):**
   - You can also view it using VS Code Live Server or Python's built-in server:
     ```bash
     python -m http.server 8000
     ```
   - Open `http://localhost:8000/` in your browser.

## 🌐 How to Deploy to GitHub Pages
To host this project publicly on GitHub Pages without any build steps:

1. Create a new repository on GitHub (or use your existing repository).
2. Upload the project files (`index.html`, `style.css`, `fried-rice.jpg`, `README.md`).
3. In GitHub, go to **Settings** > **Pages** (under the "Code and automation" menu on the left).
4. Under **Build and deployment**:
   - **Source:** Select `Deploy from a branch`.
   - **Branch:** Select `main` (or `master`) and folder `/ (root)` or your task folder.
   - Click **Save**.
5. Wait 1–2 minutes for GitHub Pages to complete deployment.
6. Your live website URL will be:
   ```text
   https://<your-username>.github.io/<repository-name>/
   ```
